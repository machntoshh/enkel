# Política de Privacidade / Privacy Policy — Enkel

## Português (PT-BR)

O **Enkel** é um aplicativo desktop *local-first* e 100% offline.

1. **Coleta de Dados:** O Enkel **não** coleta, armazena, transmite ou compartilha quaisquer dados pessoais, textos, anotações, arquivos, imagens ou telemetria de uso para servidores externos.
2. **Armazenamento Local:** Todas as anotações (`.md`), pastas e imagens criadas pelo usuário são salvas exclusivamente no disco local do próprio computador do usuário, no diretório escolhido por ele.
3. **Serviços de Terceiros:** O aplicativo não utiliza rastreadores, anúncios, cookies ou serviços de análise em nuvem. Links externos opcionais (como a página de apoio voluntário) só são abertos no navegador padrão do sistema mediante clique explícito do usuário.

---

## English (EN)

**Enkel** is a local-first, 100% offline desktop application.

1. **Data Collection:** Enkel does **not** collect, store, transmit, or share any personal data, notes, files, images, or usage telemetry with any external servers.
2. **Local Storage:** All Markdown notes (`.md`), folders, and images created by the user are stored exclusively on the user's own local storage device in their chosen directory.
3. **Third-Party Services:** The application does not use trackers, advertisements, cookies, or cloud analytics. Optional external links are only opened in the system's default browser when explicitly clicked by the user.
